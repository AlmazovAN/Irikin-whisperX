# P02 — локальная диагностика Windows перед установкой WhisperX

Цель: получить факты о среде **без** установки AI-библиотек, загрузки моделей,
отправки аудиозаписей или изменения конфигурации приложения.

## Запуск

Откройте командную строку в папке репозитория (установки WhisperX не требуется):

```bat
python scripts\diagnose_environment.py
```

Для структурированного отчёта:

```bat
python scripts\diagnose_environment.py --json --output "%USERPROFILE%\Desktop\whisperx-preflight.json"
```

Если уже установлен PyTorch и его импорт вызывает сбой либо требует слишком много времени,
временно используйте `--skip-torch`; отчёт явно укажет, что проверка CUDA пропущена.
Если нужно проверить **только действительность** токена Hugging Face, задайте его в
переменной окружения `HF_TOKEN` и **явно** добавьте `--check-hf`. Этот флаг обращается
по HTTPS к `huggingface.co/api/whoami-v2`. Без флага запросов к Hugging Face нет.
Диагностический JSON не содержит сам токен, пароль или содержимое `.env`.
Не публикуйте отчёт целиком без предварительного просмотра: он содержит состав оборудования.

## Что и как проверяется

| Группа | Механизм | Ограничения |
| --- | --- | --- |
| ОС и Python | `platform`, `sys.version_info` | В текущем README заявлен Python 3.10–3.12; за пределами диапазона выдаётся блокер **поддержки**, не доказательство несовместимости |
| RAM | Windows `GlobalMemoryStatusEx` | Для Linux/macOS отмечается «не применимо» |
| Диск | `shutil.disk_usage` для каталога проекта | Менее 5 GiB помечается предупреждением, а не доказательством нехватки |
| FFmpeg/FFprobe | Проверка PATH и `-version` с таймаутом | Проверяется запуск бинарника, не кодеки и декодирование конкретного файла |
| GPU | PowerShell `Get-CimInstance Win32_VideoController` | `AdapterRAM` у встроенной графики и в WMI может быть недостоверным; **не считать** его подтверждённой выделенной VRAM |
| NVIDIA VRAM | `nvidia-smi` (если установлен) | Только NVIDIA; значение `memory.total` в MiB, не доступная память |
| PyTorch | Только если пакет установлен: импорт и CUDA/XPU device checks | Проверка CUDA не является тестом WhisperX или поддержкой ROCm/DirectML |
| Библиотеки | `importlib.metadata.version`, без импорта моделей | Установленная версия не доказывает совместимость API |
| Hugging Face | Присутствие `HF_TOKEN`/`HUGGING_FACE_HUB_TOKEN`; онлайн-проверка только по `--check-hf` | Даже HTTP 200 подтверждает **аутентификацию**, но **не доступ** к gated-моделям Pyannote |

Формат отчёта JSON: `schema_version`, `system`, `python`, `ram`, `disk`, `ffmpeg`,
`ffprobe`, `windows_gpus`, `nvidia_smi`, `packages`, `torch`, `hugging_face`,
`assessment`. В `assessment` есть `blockers`, `warnings` и неизменно
`inference_validated: false`. Статус `preflight_checks_completed` означает,
что **предварительные условия обнаружены**, а не что распознавание уже работает.

Ограничения по железу (ориентиры, не требования разработчика моделей): при RAM менее
12 GiB предупреждаем о возможной нехватке памяти для Small + Pyannote;
при свободном месте менее 5 GiB — о риске загрузки моделей. Окончательное решение
зависит от профиля установки P03 и реальных испытаний P06.

### Известная конфигурация владельца (по ранее предоставленным характеристикам)

Windows 11 Home, AMD Ryzen 5 5500U с Radeon Graphics, 8 GiB установленной RAM.
**Это не результат запуска preflight на ПК.** Видеопамять и реальная поддержка
ускорения PyTorch не измерены. NVIDIA CUDA для этой AMD-графики не следует
предполагать; CPU-профиль необходимо оценивать по результатам P02/P03.

## Приёмка P02

1. Команда запускается без установленного WhisperX и корректно сообщает об отсутствующих компонентах.
2. На компьютере владельца получен JSON-отчёт, включая FFmpeg, Python, GPU и память.
3. Проверка без `--check-hf` не обращается к интернету; токены не выводятся.
4. Ошибки PowerShell, отсутствия `nvidia-smi`, PyTorch DLL и недоступного FFmpeg не завершаются необработанным исключением.
5. В CI проходят unit-тесты на имитациях Windows/AMD/NVIDIA/CPU и ошибок, без моделей и сетевого доступа.

После прохождения P02 использовать **реальный** диагностический отчёт для выбора
CPU/CUDA-стека в P03. Диагностика не заменяет GPU/ASR smoke-test P06.
