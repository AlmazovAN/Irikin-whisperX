# Первый запуск Irikin-whisperX (Windows, Simple Mode)

**Цель:** после первоначальной установки пользователь запускает `Start.bat`, открывает
локальную вкладку и нажимает **«Проверить готовность»**, не открывая терминал
для диагностики моделей. Первое распознавание автоматически загружает
недостающие доступные веса через существующий WhisperX/Hugging Face pipeline.

## Нужна только одна первоначальная установка

1. Python должен быть 3.10–3.12 (3.11 — рекомендуемый, но уже установленный
   подходящий Python не надо заменять). Официальный сайт: https://www.python.org/downloads/windows/
2. Для получения/обновления исходников: Git https://git-scm.com/downloads/win
   (если папка приложения уже скачана, непосредственно для распознавания не нужен).
3. FFmpeg и FFprobe доступны из PATH. Сайт проекта: https://ffmpeg.org/download.html
4. Из папки проекта первый раз выполнить `Install.bat --profile cpu`. На
   AMD Ryzen 5 5500U со встроенной Radeon CUDA-профиль не выбирать.
   Установщик не заменяет системные Python/Git/FFmpeg и не удаляет чужой venv.

## Обычное использование

1. Двойной щелчок по `Start.bat` — один локальный сервер Gradio,
   браузер откроется на http://127.0.0.1:7860/.
2. В разделе **«Проверка готовности»** запустить проверку (также выполняется
   при открытии страницы). При отсутствии зависимостей интерфейс выдаёт
   конкретные наименования и не показывает фиктивный PASS.
3. Для разделения спикеров Hugging Face требует ОДИН РАЗ войти в аккаунт
   и принять условия обоих моделей:
   - https://huggingface.co/pyannote/speaker-diarization-3.1
   - https://huggingface.co/pyannote/segmentation-3.0
   Создать личный read-токен: https://huggingface.co/settings/tokens
4. В раскрывающемся блоке **«Hugging Face — первоначальная настройка»**
   вставить токен и нажать **«Сохранить токен на этом ПК»**.
   Токен сохранится в исключённом из Git файле `.env` в корне проекта,
   **в открытом виде**. Не отправлять его в переписку, PR или логи.
   На общем компьютере это не вариант защищённого хранилища.
5. Проверить готовность повторно, затем выбрать аудиофайл и запустить задачу.
   Веса Whisper/Pyannote при отсутствии в кэше загружаются самим pipeline
   во время первой обработки. Пользователь отдельно не скачивает файлы.
6. Оставить `Start.bat` открытым на время обработки. После приёма файла
   вкладку можно закрыть, но не сервер и не компьютер. После завершения
   доступен TXT и история.

## Чего автоматическая проверка НЕ доказывает

- Принятие токена Hugging Face (`whoami-v2`) **не** подтверждает
  разрешение скачать gated-файлы обеих моделей. Доступ проверяется при
  реальной загрузке. Программа не принимает соглашения от имени пользователя.
- Наличие библиотек, FFmpeg и токена **не** равно успешной инференции.
  Проверка модели, диаризации на двух голосах и вместимости в 8 ГБ RAM
  по-прежнему выполняется по `docs/qa-mvp.md`.
- Если необходимые зависимости или FFmpeg не установлены, `Start.bat`
  может остановиться до открытия веб-интерфейса. Полностью автономный
  системный bootstrap-install без установленных Python/FFmpeg — **не
  реализован**. Это отдельная задача упаковки Windows-приложения.

## Безопасность

- Доступ только через `127.0.0.1`, не публичный share.
- Файл `.env` игнорируется Git, но это не шифрование; заботиться об
  учётной записи Windows и резервных копиях следует как о других секретах.
- Проверка готовности не передаёт аудио и не скачивает модели; онлайн
  запрос проверки токена идёт в Hugging Face только с локального ПК.
- Пароли и токены не выводятся в ответах UI/диагностике.
