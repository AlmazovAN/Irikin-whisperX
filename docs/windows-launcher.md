# P05 — Windows Launcher: один `Start.bat`

**Статус:** реализована проверяемая логика запуска; на целевой Windows 11 и полном
WhisperX-окружении запуск не проверен. P05 не означает готовность MVP.

## Быстрый запуск

После успешного `Install.bat --profile cpu` из P03:

1. Откройте папку репозитория в Проводнике Windows.
2. Дважды нажмите **`Start.bat`**.
3. Останется открытым окно консоли с диагностикой и логом.
4. Запуск браузера происходит **только после ответа локального HTTP-сервера** по
   адресу `http://127.0.0.1:7860/`. Если браузер не открылся, адрес
   можно скопировать из окна консоли.
5. Для остановки нажмите **Ctrl+C** в консоли, подтвердите запрос Windows,
   если он появился. Python старается завершить дочерний сервер корректно,
   затем освобождает процесс; результат виден в консоли и логе.

**Не нужно запускать отдельно** `backend/main.py`, Uvicorn или второй WebUI:
для P05 стартует только один `app.py` с интерфейсом Gradio.
Закрытие браузера не выключает сервер; закрытие консоли завершает сессию
и не гарантирует сохранение ещё не реализованных фоновых задач.

## Что проверяет Start

- Наличие `venv/Scripts/python.exe`; **ничего не скачивается и не
  устанавливается**. Если нет окружения, показана команда установки.
- Изолированный запуск Python-скрипта оболочки через `-I`.
- Профиль P02 через `diagnose_environment.py --json --skip-torch`:
  версия Python, FFmpeg/FFprobe, наличие ключевых пакетов. Это **не**
  импорт всех библиотек и не доказательство работоспособности
  транскрибации; принудительная загрузка моделей **не выполняется**.
- Занятый порт 7860 и второй запущенный экземпляр launcher. Нет
  попытки убить посторонний процесс или открыть чужой веб-интерфейс.
- Наличие HTTP-ответа и время ожидания до 180 секунд по умолчанию.
  При неудаче пишет причину и завершает запущенный процесс.

## Дополнительные команды (`cmd` из корня репозитория)

| Команда | Назначение |
| --- | --- |
| `Start.bat` | Обычный запуск |
| `Start.bat --check-only` | Проверить окружение и порт, не запускает сервер и не открывает браузер |
| `Start.bat --no-browser` | Запустить сервер без открытия браузера |
| `Start.bat --port 7870` | Выбрать другой локальный порт |
| `Start.bat --startup-timeout 300` | Увеличить ожидание готовности до 300 секунд |

Допустимы только локальные параметры; опасные старые опции
`--share`, `--api_open`, `--server_name` и `--allowed_paths`
**не принимаются**. Актуальные настройки безопасности остаются
в P04 — [локальная безопасность](local-security.md).
Для диагностики можно отдельно использовать
`venv\Scripts\python.exe scripts\diagnose_environment.py --json`.

`start-webui.bat` теперь делегирует запуск в `Start.bat`;
`user-start-webui.bat` остаётся совместимым с пустыми параметрами,
но некоторые устаревшие пользовательские аргументы намеренно запрещены
при запуске в локальном режиме. Для входа с паролем через CLI этот
launcher не предназначен.

## Логи

Файлы создаются по схеме `logs/start-YYYYMMDD-HHMMSS-PID.log`.
Логи содержат сообщения оболочки и текстовый поток stdout/stderr сервера;
папка `logs/` игнорируется Git. Ошибка отсутствия `venv`, когда
Python ещё нельзя запустить, выводится в консоль и отдельно в
`logs/start-bootstrap-error.log`.

**Важно:** ошибки сторонних библиотек могут случайно содержать имена
файлов, личные данные или значения параметров. Логи являются
локальными: прежде чем отправить их кому-либо, проверьте и
обезличьте содержимое. Токены никогда не записываются оболочкой
намеренно; **полное отсутствие секретов в сторонних трассировках
не гарантируется**.

## Различие между проверками

- **Юнит-тесты P05**: подменённый процесс, подменённый отчёт P02,
  локальный путь, отсутствие реальных аудиомоделей и сети.
- **Windows-acceptance (не выполнен)**: дважды кликнуть `Start.bat`,
  увидеть `READY`, открыть страницу, закрыть вкладку без остановки
  сервера, повторный Start блокируется, остановить Ctrl+C, проверить
  закрытие порта 7860 и появление лога.
- **P06**: проверить настоящий WAV/MP3, Whisper Small, alignment и
  diarization. Отсутствие моделей/токена на P05 ещё не доказывает
  неисправность launcher.

На ноутбуке Ryzen 5 5500U + интегрированная AMD Radeon + 8 ГБ RAM
планируемый профиль — CPU. CUDA NVIDIA не применяется автоматически.

## Ограничения

- Ветки P01–P04 ещё не приняты и не слиты; P05 базируется поверх P04.
- Предотвращение повторного запуска и CTRL_BREAK на Windows реализовано,
  но без реального Windows-прогона и тестов внешних дочерних процессов
  не может считаться полностью проверенным.
- Launcher не является Windows Service, не запускается после перезагрузки
  автоматически, не восстанавливает ASR-задачи и не управляет фоновыми
  задачами. Эти функции — следующие этапы дорожной карты.
