# P07 — единый профиль локального MVP

**Область:** этап 1, чат 02, P07. Без нового inference-конвейера, интерфейса очереди и Drive.

## Канонический профиль

Источник истины: `modules/mvp/preset.py` (`MVP_PRESET`, `build_mvp_pipeline_params`).

| Параметр | Значение |
|---|---|
| Модель | WhisperX `small` |
| Язык / задача | `ru` / `transcribe` (без перевода) |
| VAD | включён |
| Alignment | включён через WhisperX |
| Диаризация | включена через WhisperX/Pyannote, требуется для приёмки |
| Результат | `txt` (экспорт transcript TXT/JSON реализуется в следующих PR) |
| По умолчанию | `cpu`, `int8`, `batch_size=1` для ноутбука с интегрированной Radeon |
| Музыкальное разделение | выключено |

`build_mvp_pipeline_params()` возвращает **новый** экземпляр существующего
`TranscriptionPipelineParams` каждый раз. Его могут использовать будущие UI,
JobService и CLI, не определяя свои независимые настройки. `HF_TOKEN` не
сериализуется в параметрах и считывается уже существующим runtime из среды.

Диагностический режим `diarization_enabled=False` **не является** принятым MVP.
Выбор CUDA явный; без доказанного наличия NVIDIA запуска не предполагается.

## Совместимость и сохранность конфигурации

- `configs/default_parameters.yaml` оставлен без изменений: это настройки
  существующего Advanced UI, а **не** источник MVP.
- При вызове `BaseTranscriptionPipeline.run(..., persist_settings=False)`
  текущий MVP/CLI не перезаписывает отслеживаемый файл параметров.
  Старые обработчики без аргумента сохраняют прежнее поведение до UI-рефакторинга.
- Существующая обработка языка Gradio (название языка → `ru`) сохранена;
  дополнительно допускается прямой код `ru` от MVP или фонового задания.
- CLI `scripts/smoke_whisperx.py` использует тот же `build_mvp_pipeline_params`,
  не содержит второго перечня параметров.

## Приёмка и ограничения

Автономные тесты: `python -m pytest -q tests/unit/test_mvp_preset.py tests/unit/test_smoke_whisperx.py`.
Они не загружают веса и не подтверждают реальную работу Pyannote.
До P11 требуется Windows smoke с русским аудио, двумя спикерами и
зафиксированным временем/памятью на целевом ноутбуке. Результат в JSON/TXT,
надёжная очередь и UI реализуются в P09–P25, не в P07.
