# P03 — установка Irikin-whisperX на Windows

**Статус:** набор версий — согласованный по опубликованным метаданным **кандидат**, а не подтверждённая работа WhisperX на ноутбуке. До реальной установки, `pip check` и P06 smoke-test не считать среду принятой.

## Аппаратный профиль

По предоставленным характеристикам: Windows 11 Home, Ryzen 5 5500U, встроенная AMD Radeon Graphics, 8 ГБ RAM. Для этого ПК **выбирать CPU**, а не NVIDIA CUDA. CUDA 12.6 применима только к поддерживаемой видеокарте NVIDIA с установленным драйвером; `--profile cuda126` имеет проверку через `nvidia-smi`. **CPU-обработка на 8 ГБ может быть очень медленной, а диаризация — ограничена памятью.**

Перед установкой получить фактический отчёт P02:
```bat
python scripts\diagnose_environment.py --json
```

## Рекомендуемые действия

1. Установить 64-битный Python 3.11, Git и FFmpeg/FFprobe в PATH. Версии Python 3.10 и 3.12 также допущены установщиком, но не проверены на целевом ПК.
2. Открыть `cmd` в корне репозитория.
3. Проверить план команд **без скачивания и создания окружения**:
   ```bat
   Install.bat --profile cpu --dry-run
   ```
4. Для фактической установки:
   ```bat
   Install.bat --profile cpu
   ```
5. Только при **наличии подтверждённой NVIDIA GPU** и совместимого драйвера:
   ```bat
   Install.bat --profile cuda126
   ```
6. После установки:
   ```bat
   venv\Scripts\python.exe scripts\diagnose_environment.py --json
   venv\Scripts\python.exe -m pip check
   ```

Установщик сначала устанавливает согласованную тройку PyTorch из **одного выбранного индекса**, затем остальные зависимости из обычного PyPI и GitHub. Не смешивает CPU и CUDA индексы при разрешении остальных библиотек.

При существующем `venv` установщик **останавливается, ничего не удаляя**. Чтобы продолжить установку, **только если** окружение уже было создано данным установщиком и профиль не изменился, использовать:
```bat
Install.bat --profile cpu --reuse-venv
```
Для чужого/старого `venv`: сначала сделать резервную копию или переименовать его **вручную**. Никаких автоматических удаления и перезаписи окружений.

## Зафиксированная кандидатная матрица

| Компонент | Версия | Причина |
| --- | --- | --- |
| Python | 3.11 x64 (допустимы 3.10–3.12) | Поддерживаемый диапазон старого приложения и WhisperX 3.4.2 |
| PyTorch / TorchAudio / TorchVision | 2.7.1 / 2.7.1 / 0.22.1 | Официальная согласованная тройка PyTorch; TorchAudio 2.8 удалил используемый устаревший API |
| WhisperX | 3.4.2 | В опубликованном pyproject требует `torch>=2.5.1`, `torchaudio>=2.5.1`, `ctranslate2<4.5.0` |
| Pyannote Audio | 3.4.0 | Последняя линия Pyannote 3.x; Pyannote 4.x меняет API |
| CTranslate2 / Faster Whisper | 4.4.0 / 1.1.1 | Удовлетворяет ограничениям WhisperX 3.4.2 |
| NumPy | 2.2.6 | Удовлетворяет требованию `numpy>=2.0.2`, старое ограничение проекта `numpy<2.3` |
| Gradio | 5.49.1 | Удерживает приложение в ветке 5.x; совместимость пользовательского UI требует проверки |
| ONNX Runtime | 1.20.1 (CPU) | Вместо `onnxruntime-gpu` в CPU-профиле, без наложения двух пакетов на один namespace |

Прямые основные зависимости зафиксированы в `requirements.txt` и `requirements/torch.txt`.
**Это не полный lock-файл с хешами транзитивных wheel-файлов**: вторичные зависимости и сборки могут меняться. Ревизии исходников UVR и pyrubberband закреплены SHA. Для подтверждённой воспроизводимости требуется сборка/протокол успешной установки на целевой Windows с сохранённым `pip freeze` и выводом `pip check`.

## Разделение CPU и NVIDIA CUDA

| Профиль | Индекс Torch wheel | Условия |
| --- | --- | --- |
| `cpu` (по умолчанию) | `https://download.pytorch.org/whl/cpu` | Любой x64 Windows, в том числе AMD iGPU; **не подразумевает GPU-ускорения** |
| `cuda126` | `https://download.pytorch.org/whl/cu126` | NVIDIA, CUDA-совместимый драйвер, успешная диагностика P02 |

Windows + AMD Radeon встроенная графика **не равна** NVIDIA CUDA; установка AMD ROCm и DirectML этим PR не реализуется. Чистый `pip install -r requirements.txt` **не выбирает** индекс CPU/CUDA, поэтому рекомендуемый путь — `Install.bat`. Linux/macOS-установщик оставлен без изменений.

## Ошибки и ограничения

- Если `pip` сообщает о конфликте, фиксировать полный текст ошибки. **Не лечить его массовым обновлением** библиотек без проверки.
- `pip check` подтверждает согласованность **метаданных** зависимостей, не работу моделей или отсутствие CUDA OOM.
- Токены Hugging Face хранятся отдельно от Git; диаризация может требовать согласия с условиями модели.
- Отсутствие FFmpeg влияет на обработку аудио; установщик PyPI-пакетов не заменяет установку FFmpeg.
- Проблемы UVR/GitHub/компиляции сторонних пакетов могут остановить установку; это ещё не основание менять рабочий ASR-код.
- Из-за лимита 8 ГБ RAM и AMD iGPU успешный запуск Small + Pyannote не гарантируется и проверяется отдельно в P06.

## Источники проверки версий

- PyTorch: https://pytorch.org/get-started/previous-versions/ — официальные wheel-индексы для 2.7.1.
- WhisperX 3.4.2: https://github.com/m-bain/whisperX/blob/v3.4.2/pyproject.toml — опубликованные требования.
- Pyannote 3.x: https://github.com/pyannote/pyannote-audio/blob/main/CHANGELOG.md — изменение веток 3.x и 4.x.
- Противоречие с TorchAudio 2.8: https://github.com/m-bain/whisperX/issues/1295 — пример ошибки удалённого `AudioMetaData`.
