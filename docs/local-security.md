# P04 — безопасный локальный режим

**Цель:** single-user Windows WebUI на одном ПК. По умолчанию приложение не
публикует Gradio share, не привязывается ко всем сетевым интерфейсам и не
сохраняет API-ключи в параметрах распознавания. Это не multi-user/web-hosting
security review.

## Границы доступа

| Поверхность | Изменение |
| --- | --- |
| Gradio UI | `--server_name 127.0.0.1` по умолчанию; `--share true`, `--api_open true` и любой внешний `--server_name` завершаются ошибкой **до загрузки моделей** |
| `--allowed_paths` | Вместо `eval()` используется `json.loads()`; разрешён каталог `--output_dir` и его вложенные каталоги. Выход за пределы через `../` и symlink запрещён |
| Открытие папки | Нет команды shell `start <путь>`; Windows использует `os.startfile` |
| FastAPI | ASGI gate отклоняет чужие IP, Host и Origin; HTTP получает 403, WebSocket закрывается с кодом 1008 |
| CORS | Только `http(s)://localhost`, `127.0.0.1`, `[::1]`; звёздочка убрана; дополнительно проверяется соответствие порта Origin и Host |
| Состояния задач | Токен из `task_params` исключается перед записью в SQLite и из API-ответов старых задач |
| Настройки YAML | Ключи `hf_token`, `api_key`, `password`, `access_token`, `refresh_token`, `client_secret` очищаются при сохранении; старый локальный YAML очищается **в памяти** при загрузке настроек |
| Пароли в UI | Поля HF Token и DeepL API Key маскируются при вводе |

Пример локального запуска (из корня репозитория, после P03):

```bat
start-webui.bat --server_name 127.0.0.1 --share false --api_open false
```

Пользовательский `user-start-webui.bat` может содержать старые флаги
`SHARE=true`, `API_OPEN=true` или иной `SERVER_NAME` — они теперь
вызывают явную ошибку; следует оставить их пустыми/выключенными.

### Папки

По умолчанию Gradio может выдавать результаты только из `outputs/`.
Если нужен дополнительный вложенный каталог, поддерживается JSON-массив:

```bat
start-webui.bat --allowed_paths "[\"C:\\path\\to\\outputs\\subdir\"]"
```

Абсолютный путь должен быть внутри фактического `--output_dir`.
Подключить любую папку диска через параметр теперь нельзя. При
попытке указать другой каталог сервер не запускается. **Исходники аудио
не следует хранить в каталоге, разрешённом для скачивания результата.**

### Секреты

Создать локальный `.env` рядом с `app.py` по образцу
[.env.example](../.env.example); **не заполнять образец настоящими ключами**.

```dotenv
HF_TOKEN=... 
DEEPL_API_KEY=...
```

WebUI загружает локальный `.env` только при запуске, не перезаписывая
уже установленные переменные среды. Пустой HF Token в форме берётся
из `HF_TOKEN` при фактической диаризации. DeepL в старом UI по-прежнему
принимает ключ вручную в маскируемом поле; функция автоматического
использования ключа из среды для DeepL **не включена в P04**.

**Старые сохранённые секреты:** если токен был записан ранее в
`configs/default_parameters.yaml`, новая версия не покажет его в форме
и не сохранит его снова. Однако старые байты остаются в существующем
файле до следующей перезаписи. Если файл использовался ранее, проверьте
его на `hf_token` и `api_key`, удалите старые значения локально и
при необходимости перевыпустите компрометированные токены.

Для отдельного FastAPI backend сохранён legacy-путь
`backend/configs/.env`; следует хранить там только разрешённые
секреты и не выкладывать их в GitHub.

### Уже отслеживаемая backend/records.db

В репозитории на момент аудита находится **отслеживаемый Git файл**
`backend/records.db`. Добавление правил в `.gitignore` **не удаляет**
его из истории и не делает неотслеживаемым. В P04 БД **не удаляется,
не обнуляется и не переносится автоматически**, чтобы не потерять
имеющиеся записи. Содержимое БД на конфиденциальность не проверено.
Перед публикацией реальных заданий необходим отдельный перенос
базы в `data/` и `git rm --cached` с проверкой истории; изменение
схемы и миграция будут рассмотрены в P13.

Дополнительно игнорируются `data/`, `logs/`, файлы `.env.*`,
sidecar-файлы SQLite. `.env.example` остаётся доступным для Git.

### Остаточные ограничения

- `localhost` и закрытый API не являются полноценной защитой от
  вредоносного локального ПО или обратного прокси, запущенного на том
  же компьютере.
- Если отдельный FastAPI запускать через Uvicorn, рекомендуется
  `uvicorn backend.main:app --host 127.0.0.1 --port 8000`.
  Параллельный запуск Gradio и FastAPI на одной GPU не рекомендован
  до утверждения общего job runtime.
- `TEST_ENV=true` позволяет только внутреннюю синтетическую пару
  `testclient/testserver` для `fastapi.testclient.TestClient`.
  **Никогда не задавать `TEST_ENV=true` при обычном запуске сервера.**
- CORS сам по себе не блокирует все межсайтовые запросы; локальный
  ASGI gate проверяет и IP, и Host, и Origin.
- Ни Windows запуск, ни интеграционные тесты Gradio/FastAPI
  на реальном стеке в этом PR не подтверждены.

## Приёмка

1. Unit-тесты `tests/unit/test_local_security.py` без AI-пакетов.
2. Gradio defaults: loopback + share/api off; `eval` отсутствует.
3. Подмена Host, внешний IP, другой Origin и port отклоняются в FastAPI.
4. YAML и новое сохранение Task не содержат токенов; legacy API их
   не возвращает.
5. Проверка на реальной Windows-машине с библиотеками после P03:
   загрузить MP3, создать результат и скачать его из `outputs/`.
6. Не удалять `backend/records.db`; перенос отдельно.
