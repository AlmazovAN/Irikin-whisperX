# P23 / GitHub PR #24 — скачивание TXT в Simple Mode

**Базовый master:** `b6dbb48c8b63e6da2d947d1ae9a113c8d070c31b` (после P22 / GitHub PR #23).
**Ветка:** `feature/p23-transcript-download`.

## Что реализовано

- Вкладка Simple содержит `gr.DownloadButton("Скачать TXT")`.
- В `Blocks.load()` / `Timer.tick()` теперь используется
  `SimpleModeController.poll_with_download(uuid)`. Пока задание не
  `COMPLETED`, кнопке не выдаётся путь. После подтверждённого завершения
  `JobService.get_artifact(uuid, format="txt")` проверяет UUID, статус,
  номер попытки, пути в SQLite и SHA-256 опубликованных TXT/JSON.
- Для штатного скачивания используется стандартный файловый маршрут Gradio
  (встроенный endpoint `/gradio_api/file=...`, без второго FastAPI/worker).
  Путь к файлу **всегда** выводится из доверенного `JobService`;
  введённый браузером произвольный путь к файлу не принимается.
- Запуск `Start.bat` устанавливает рабочий каталог в корень репозитория:
  Gradio может отдавать возвращённые callback-файлы из текущего каталога.
  Новых `allowed_paths` для всего `data/jobs/` нет; аудио/JSON не
  становятся отдельными публичными endpoint.
- `DownloadButton.change` выполняет JS, который один раз на UUID
  предпринимает нажатие кнопки при появлении проверенного файла.
  UUID попытки хранится отдельно в `localStorage` того же localhost.
  Скрипт не отправляет результат во внешнюю сеть, не читает данные аудио.
- JavaScript **не может гарантировать**, что браузер сохранит файл:
  браузер может заблокировать автоматическое действие без жеста пользователя,
  не предоставить место для сохранения или запретить загрузку.
  Поэтому видимая кнопка **Скачать TXT** остаётся обязательной и
  доступна при последующих открытиях вкладки.
- При новом принятом задании старая кнопка очищается, чтобы не отдать TXT
  другого job. При ошибке новой загрузки предыдущая проверенная
  кнопка остаётся доступной.
- Если файл пропал либо не совпадает с manifest SHA-256, ссылка не выдаётся,
  показывается уведомление о недоступности TXT, при этом исходник и JSON
  не удаляются, а повторная ASR не запускается.

## Сохранность и безопасность

Авторитетная копия: `data/jobs/<uuid>/result/attempt-N/transcript.txt`
с `manifest.json`. Gradio для браузерной выдачи может создавать
**временную копию** в своём cache, но не является хранилищем результатов.
Закрытие вкладки, ошибка автоматической загрузки и очистка браузерного cache
не удаляют сохранённый результат.

Gradio привязан только к `127.0.0.1` и `share=False`, внешний API
по умолчанию отключён. UUID — идентификатор, **не пароль**;
доступ к локальному веб-приложению следует ограничивать пользователем ПК.
Никакого общего внешнего API доступа к каталогам не добавлено.

Стандартный DownloadButton/Gradio **предполагает** рабочий каталог проекта
(гарантируется в Windows `Start.bat`). Реальные Gradio 5.49.1,
Windows 11/браузер и специфические политики автоскачивания
не проверены в безмодельных Linux тестах. Сценарии входят в P25 QA.
