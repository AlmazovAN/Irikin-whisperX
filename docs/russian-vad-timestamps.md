# P10 — принудительный русский язык, VAD и координаты исходной записи

**Этап 1 · Чат 02 · P10.** Продолжение P07–P09, без нового ASR и без UI/очереди.

## Принятый маршрут для MVP

1. P07 `build_mvp_pipeline_params()` передаёт `lang="ru"`, `is_translate=False`, `vad_filter=True`, `enable_whisperx_alignment=True`.
2. P09 `TranscriptionService` вызывает `BaseTranscriptionPipeline.run(..., strict_vad=True, persist_settings=False)`. Ручной P06 smoke использует тот же строгий режим.
3. VAD анализирует исходный файл и отдаёт пары `start/end` **в отсчётах исходного аудио 16000 Hz**. ASR WhisperX получает склеенные речевые фрагменты; `language="ru"`, `task="transcribe"`. Ни автоопределение английского, ни перевод не требуются.
4. Сегментные и, если имеются, словные координаты ASR преобразуются из сжатой шкалы времени в исходную **до** alignment. На разрывах между речевыми фрагментами начало интервала относится к следующему фрагменту, конец — к предыдущему. Паузы сохраняются в исходных координатах.
5. WhisperX alignment запускается **на исходном аудио**, с языком из принудительной настройки `ru`, а не предположением из автоматически возвращённого поля `language`. Diarization также использует исходный аудиосигнал. Это сохраняет общий базис таймкодов.
6. Если VAD не обнаружил ни одного речевого фрагмента, **строгий MVP** не запускает ASR/align/diarize на полной тишине. Он возвращает пустой сегмент для существующей проверки P09, которая выдаёт `EMPTY_TRANSCRIPT`, а не ложный успешный результат. Legacy Gradio без `strict_vad` сохраняет свой прежний fallback.

## Технические изменения

- `modules/vad/timestamps.py`: чистый Python, `SpeechTimeMap`, `restore_original_timestamps`; проверка положительных, упорядоченных и неперекрывающихся VAD чанков и значений времени.
- `modules/vad/silero_vad.py`: делегирование timestamp restore из старого SileroVAD к общей проверяемой карте.
- `modules/whisper/base_transcription_pipeline.py`: новый keyword-only `strict_vad=False` (Legacy совместимость), отказ от ASR на тишине в MVP, принудительное `ru` для alignment, оригинальное аудио для alignment/diarization.
- `modules/jobs/transcription_service.py` и `scripts/smoke_whisperx.py`: `strict_vad=True`.
- Автономные тесты добавлены в `tests/unit/test_vad_timestamps.py`, существующие mock-тесты адаптированы под новый keyword argument.

## Границы и ограничения проверки

Тесты используют программно сформированные чанки со звуком в диапазонах 0–2 с и 5–8 с, длинные записи, граничные срезы, отсутствие слов/речи, проверки порядка ASR→restore→align→diarize. Отдельный тест исполняет реальный метод `WhisperXInference._transcribe_with_fallback` с фиктивной моделью и проверяет аргументы `ru/transcribe`. Без тяжёлых библиотек и сети.

Карта рассчитана на **16 кГц** (текущая фиксированная частота SileroVAD). На реальных записях пока требуется проверить корректность chunk boundaries, шум, восстановление словных координат, адаптацию параметров Silero для коротких записей и CPU/Windows совместимость.

Тесты без весов **не подтверждают точность распознавания русской речи**. P11 отдельно проверяет alignment/Pyannote с двумя голосами; P12 нормализует формат JSON и speaker.
